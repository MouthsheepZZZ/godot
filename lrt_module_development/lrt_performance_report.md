# LRT 无损优化验证报告

> **最新目标已确认：0.05 ms 指纯 A/L 传播，规模为当前场景的 162,268 Probe。第二轮结果见文末，首轮数据保留作历史对照。**

## 首轮结论（历史记录）

本轮实现了阶段专用传播、去除不变字段搬运、末轮直接发布紧凑采样状态、传播绑定缓存、严格零 T 注入提前退出及原生资源压缩。未修改 Probe 密度、FP32 状态、迭代次数、更新频率、传播核或光照模型，无需重烘焙。

**0.05 ms 未达到。** 本场景纯 A/L 阶段中位数约 **0.648 ms**，Volume 更新约 **1.012 ms**；完整视口开关 LRT 的 GPU 时间中位数差约 **1.466 ms**。不能把前两个口径当成全部 LRT 成本，也不能将本场景数字与其他场景的 0.5 ms 直接对比。

## 环境与方法

- 场景：`res://src/scenes/combined/combined.tscn`；RTX 5080；Windows Forward+；同一 `dev_build=yes`、`optimize=none` 编辑器配置。
- 世界网格 73×21×76、车厢网格 20×22×104，共 **162,268 Probe**；A/L 每帧各 2 次；注入 4 盏灯。
- 视口 1440×900，Gather 720×450；太阳阴影 2048²、接收半径 **104.5 m**。这里使用场景实际配置，不把设计默认半径误记为实测半径。
- 通过 Godot MCP 固定控制器时间为 15 s，停止时间推进，使用 `InspectionCamera`，位置 (10, 1.7, 9)、单位朝向；不保存运行时改动。
- 先构建仅增加相同分阶段计时的基线版本，再构建优化版本。排除启动/首次 Shader 编译，稳定运行各取 **120 个不同 GPU 计时帧**；P95 用排序后第 114 项，中位数取排序后第 61 项。
- 编辑器同时存在，GPU 时钟与其他上下文未锁定。这是可复现的开发版比较，不是隔离的发行版基准；尾部有明显干扰，尤其 Gather，不据此承诺固定加速倍数。CPU 与 GPU 时间不相加。

## 功能、数值与画面

- 空气 Probe 历史、Inside 初始化/清零、共享 Edge owner 和动态发布路径未改。A 与 L 从同一帧初始缓冲序号起步，各只写自身字段，注入读取刚完成的 A；任意正迭代次数结束时两字段仍在同一最终缓冲。
- 外层末轮先完成完整发布，内层才读取边界；边界阶段只读取自身需要的 A 或 RGB L，仍包含 Inside 零状态及 SH 旋转。
- 两 Volume 各抽查 3 个 8³ Trunk，共 **3,072 Probe**。优化前后 T、LocalVis、Edge、J 与 Sky 一致；稳态 L 最大绝对差 **2.3842e-7**，A 最大绝对差 **4.7684e-7**。阶段专用编译允许 FP32 计算重排，不宣称 bitwise 等价。
- 三个同条件相机的 1440×900 截图，RGB 字节最大差均为 **1**；分别只有 **1 / 4 / 3 个通道字节**不同。这些是静态画面对比，不代替动态与数值检查。
- 临时加入已有 Color SDF 对应的动态实例，两个 Volume 共 9 个 Trunk 的几何实际变化；移动约 **7 帧**、撤回约 **4 帧**达到 CPU ready。54 个周边 Trunk 撤回后的 T、LocalVis、Edge、J 与加入前完全一致；随后受影响 GPU Trunk 的 T、Edge、J 与 CPU 一致，GPU revision 追上 CPU。帧数是本次发布响应，不是光照完全收敛时间，也没有据此声称动态更新提速。
- 正迭代数 1、3、2 的切换均检查 Inside L/A 全零、持续更新及源项有效。动态撤回后的 L 有正常传播收敛尾部，短时间比较旧稳态出现过约 0.043 的最大差；该瞬态不能冒充数值重排误差，本文的微小误差结论仅指改动前后的同条件静态对比。
- 天空日→夜→日：抽查源项绝对值和约 **117.583 → 41.706 → 117.583**，Sky SH 同步变化并恢复，60 个观察帧持续传播。

冷请求主要消耗在几何与 Probe/Edge 生成；增量请求的采样仅几毫秒，场景捕获与调度等固定成本已占较大比例。没有证据表明在本轮为增量数组写时复制引入复杂结构，比保留现有实现更划算；也没有宣称压缩会加快这些阶段。

## 第二轮：纯传播内核优化（最新）

### 实现与约束

- **空间块与 Halo 复用：** 每组 96 个线程处理 8×4×3 Probe，协作加载 10×6×5 的一格 Halo，再用 shared memory 复用 26 邻域输入。A 在加载时执行原有 Visibility 约束，避免每个邻居重复约束同一来源。固定邻域和 RGB 循环显式展开；没有跳过任何有效 Probe、边或迭代。
- **连续字段平面：** 每份 FP32 历史按 R、G、B、A 四个连续 SH4 平面排列，消除 A 的 64 B 跨字段读取。同步更新上传、注入、传播、调试和 CPU 回读；公开回读数组仍按 Probe 排列，世界共享表面采样仍为原来的 AoS 格式。
- Padding、Inside 线程必须先完成协作加载和组内屏障再退出。每轮仍完整读取旧场并写入新场，轮间保留屏障，外层完成后才给内层供给边界；没有在工作组中私自推进额外轮次。
- 最终 A / L shared memory 分别为 **4,800 / 14,400 B/组**，不超过 16 KiB。它们是执行时片上工作组存储，不是新增的逐 Volume 显存分配。常规预算仍为 **364 B/Probe**，本场景 Volume 与采样缓存仍约 **56.33 MiB**。
- 试过平方长度约束、A 的归一化变量改写和加权核重排；未得到足以排除频率变化的额外收益，均已撤回。公共 SH 函数未改变，也没有保留诊断专用旧内核、兼容分支或可选降质路径。

### 数值与响应验证

- 抽查两 Volume 的 6 个 Trunk，共 **2,260 Probe**，特意包含世界网格最后一列、最后几层以及车厢的部分块，验证非整除尺寸和嵌套边界。T、LocalVis、Edge、J 与 Sky 完全一致；最终稳态 **L 最大绝对差 3.5763e-7，A 为 1.1921e-6，S 为 5.9605e-8**。

### 目标差距

**0.05 ms 纯传播仍未达标。** 最终约 0.2775 ms，超出约 **0.2275 ms / 5.55 倍**。A 单独约 0.100 ms，L 单独约 0.178 ms；去掉 Gather 或换用更窄统计范围都不能使当前传播达标。

主要剩余工作仍是 26 邻域 SH 运算、逐邻居 Visibility 约束及每帧完整 A/L 迭代。这里没有 GPU 指令级剖析，不能把这些阶段时间进一步冒充已测出的独占 ALU/带宽占比，也不能断言所有保持质量的优化都不可能达到目标。当前结果只证明本轮改动的收益与差距；若预算必须硬约束为 0.05 ms，仍需进一步的内核级研究，或由用户另外决定是否接受密度、迭代/更新频率、精度、传播模型的取舍。本轮没有使用这些取舍，也不再要求用户重复确认已经明确的统计口径。
